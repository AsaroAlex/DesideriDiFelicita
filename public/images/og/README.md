# Immagini · Open Graph (social)

Immagini servite direttamente (NON ottimizzate da Astro): anteprima per le
condivisioni su WhatsApp/Facebook/Instagram, favicon o asset statici.

**Immagine OG consigliata:** `og-default.jpg`, dimensioni **1200×630 px**.

Dopo il caricamento, in `src/data/images.ts`:
```ts
export const ogImage = 'images/og/og-default.jpg';
```
